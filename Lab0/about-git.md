1. Git хранит ветку как указатель на коммит, и переключение между ветками не требует копирования всех файлов — просто меняется состояние рабочей директории. Копия папки — это отдельный набор файлов, не связанный с историей и другими копиями.
2. История не пропадёт: вся она хранится в скрытой папке .git, а не в самих файлах проекта.
3. PR — это запрос на слияние вашей ветки в main с возможностью просмотреть изменения и обсудить их до принятия. Он нужен, чтобы не ломать основную ветку: изменения сначала проверяются, ревьюятся и только потом попадают в main.
